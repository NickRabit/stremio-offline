Focus

The accent means focus

On the web the orange gradient marks the primary action. On TV it moves with the cursor: a focused control fills with the accent and grows 6–8 %; an unfocused primary is only tinted. One rule, readable from the sofa.

Navigation

The web sidebar becomes a rail

Same sections and icons as the web sidebar, collapsed to icons with the same accent bar on the current section. It opens with labels when focus enters it; Back from any row goes to the rail.

Home

A backdrop that follows focus

The rows are the server's /api/home cards in server order. The top shows the focused card's art and text instead of a fixed resume hero. The addon row loads as placeholders first.

Scale

10-foot sizes

Body text 24 px or more on a 1920×1080 canvas, titles 68–84 px, posters 220×330, wide cards 400×225. Everything stays inside a 5 % overscan safe area (toggle it under the pad).

Player

OK pauses, arrows seek

With no controls shown, OK pauses and opens them, left and right jump 10 s with a bubble and a thin progress line. The mode line says whether the server converts anything.

States

Nothing spins forever

Every failure ends in a panel that names the server, says what was saved and offers one way forward. Try it on the Offline screen.
